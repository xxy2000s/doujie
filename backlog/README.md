# Backlog

This directory records confirmed limitations and planned improvements that are not yet delivered.

Each item should include:

- the observed behavior and reproduction conditions;
- verified evidence separated from assumptions;
- the current workaround;
- candidate implementation directions;
- acceptance criteria and regression tests.

Move an item into the appropriate `docs/` category when the behavior is implemented and stable. Do not use backlog files as proof that a feature already exists.
